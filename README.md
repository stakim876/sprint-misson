# 판다마켓 (피그마 1~6)

다시 만들어 보기 쉽게 **만든 순서대로 번호**를 붙였습니다.

## 실행

```bash
npx serve .
```

브라우저에서 `http://localhost:3000` 접속

## 파일 순서

| 번호 | 폴더 | 화면 |
|------|------|------|
| 01 | `01_landing/` | 랜딩 페이지 |
| 02 | `02_login/`, `02_signup/` | 로그인 / 회원가입 |
| 03 | `03_additem/` | 상품 등록하기 |
| 04 | `04_items/` | 중고마켓 |
| 05 | `05_item-detail/` | 상품 상세 |
| 06 | `06_board/`, `06_board-write/`, `06_board-detail/` | 자유게시판 |

## 공통

- `css/` — 공통·페이지별 스타일
- `js/` — 스크립트
- `images/`, `icons/` — 이미지 에셋

루트 `index.html`은 위 1~6으로 바로 가는 목차 페이지입니다.
